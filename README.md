# whereis

在 Linux 上即时搜索文件名，思路来自 Windows 的 *Everything*。它不遍历目录树，而是只读打开块设备、
直接解码 ext4 文件系统自身的元数据，因此在 50 万条目的文件系统上做一次完整搜索约需 0.1 秒。

**简体中文** · [English](README_en.md)

## 环境要求

* Linux，且根文件系统是块设备上的 **ext4**
* **root** —— 读取块设备需要

## 安装

```sh
cargo build --release     # 产物：target/release/wis
```

也可以从 [GitHub Releases](https://github.com/YuleBest/whereis/releases) 直接下载静态二进制
（x86_64 或 arm64，下载后先 `chmod +x`）或 `.deb` 安装包。

包名是 `whereis`，安装出来的命令却叫 `wis`：`/usr/bin/whereis` 已被 util-linux 的同名工具占用，
同名安装会把它遮蔽。这与 ripgrep 的安排一致——包名 `ripgrep`，命令 `rg`。

## 用法

```
wis [选项] <名称>...
```

`<名称>` 匹配的是**文件名**而非完整路径，并且按原始字节匹配，所以非 UTF-8 文件名同样可用。
默认是不区分大小写的子串匹配，加 `-r` 后视为正则表达式。可以给多个名称，名称之间是 OR；
加 `-l` 后每个名称按逻辑表达式解析。

| 选项 | 含义 |
|---|---|
| `-r`, `--regex` | 把 `<名称>` 当作正则表达式 |
| `-l`, `--logical` | 把每个 `<名称>` 当作逻辑表达式：大写 `AND`、`OR`、`NOT`，相邻两项等价于 AND，括号可嵌套 |
| `-n`, `--limit <N>` | 最多输出 N 条，在排序之后应用 |
| `-s`, `--sort <键> [方向]` | 排序键：`path`（默认）、`name`、`ext`、`size`、`mtime`；方向 `asc`（默认）、`desc` |
| `-d`, `--device <路径>` | 扫描指定块设备，而非挂载在 `/` 的文件系统 |
| `-p`, `--path <路径>` | 只搜索该绝对路径（目录）之内的条目；与 `-r` 同用时路径视为正则表达式，匹配到的目录会被递归搜索 |
| `-t`, `--type <类型>[,类型2]...` | 只搜索指定类型，逗号分隔或重复给出；`file`/`f` 指普通文件，`directory`/`d` 指目录；不指定则不过滤 |
| `-b`, `--base <序号>` | 只在该历史记录的结果集里搜索；序号从最近一条往前走，`1` 是最近一次，最多 `10` |
| `--line <字段>[,字段2]...` | 自定义路径前的列及其顺序，逗号分隔：`mode`、`mtime`、`size[=auto\|b\|k\|m\|g\|t]`、`user`、`group`、`nlink`（默认 `mode,mtime,size`） |
| `-j`, `--threads <N>` | 并发读取数，默认 16 |
| `--lang <语言>` | 强制输出语言：`zh-Hans`、`zh-Hant`、`en` |
| `-c`, `--clean` | 只输出纯路径，不显示列和统计信息（优先于 `--line`） |
| `-q`, `--quiet` | 输出超过 1000 行时也不询问，直接全部输出 |
| `-h`, `--help` / `-V`, `--version` | 显示帮助 / 显示版本 |

```console
$ sudo wis sshd_config                   # 子串搜索
$ sudo wis -r '^libssl\.so\.[0-9]+$'     # 正则搜索
$ sudo wis -s size desc -n 10 '\.log$'   # 按大小倒序取前 10 个日志
```

### 逻辑表达式

加 `-l` 后，大写 `AND`、`OR`、`NOT` 是运算符，优先级 `NOT` > `AND` > `OR`；
相邻的两项等价于 `AND`。括号可以任意嵌套，双引号内的内容整体作为一个项，
正则模式下其中的括号和空格不会被当成语法。

```console
$ sudo wis -l 'example AND ( .mp4 OR .mp3 )' 'apple NOT .txt'
```

这条命令会匹配：名字同时含 `example` 和 `.mp4` 或 `.mp3` 的条目，或者含 `apple`
且不含 `.txt` 的条目。多个名称、多个表达式之间都是 OR。要搜索字面上的括号、引号，
或者大写的 `AND`，用双引号包起来，例如 `"AND"`。

结果每行一条，默认在路径前依次输出三列：`mode`（4 位八进制权限位）、
`mtime`（本地时间，格式 `2025-01-01 00:00:00`）和 `size`（1024 进制自适应单位）。
列宽按本次结果对齐，路径始终在最后：

```console
$ sudo wis sshd_config
0644 2026-10-08 01:23:45 5.2K /etc/ssh/sshd_config
```

`-c` 只输出纯路径。`--line` 可以自定义列及其顺序，例如
`--line user,group,nlink,size=k,mtime`；列顺序即显示顺序，结果排序仍由 `-s` 控制。
用户名和组名通过系统 NSS 解析，查不到时显示数字。统计信息只走 stderr，stdout 不混杂状态输出。

目录名在终端上显示为蓝色，命中的搜索词高亮为红色；管道、重定向、设置了 `NO_COLOR`
或 `TERM=dumb` 时不着色。路径本身不会改变，也不会追加尾随斜杠。
`file` 指普通文件；符号链接、设备、FIFO、socket 等特殊条目只在不加 `-t` 时出现。

一次要输出的结果超过 1000 行时，程序先输出前 1000 行，然后在 stderr 上询问是否继续，
只有输入 `y` 才输出剩余部分。该询问仅在 stdin、stdout、stderr 都是终端时出现，
管道、重定向和脚本中不会被打断。

## 历史记录

每次成功的搜索都会把完整命中集写入 `wis_history`，空结果也写，失败的搜索不写；只保留最近 10 条。
文件按惯例放在 `$XDG_STATE_HOME/wis_history`，未设置时是 `~/.local/state/wis_history`；
用 sudo 运行时文件归调用者所有。`-b 1` 是最近一条记录，`-b 2` 是上一次，依次类推。

基于记录搜索会重新扫描文件系统，只保留路径仍在记录里的条目，所以已删除的文件不会出现，
本次结果也会成为新记录。记录用 NUL 分隔，文件名里有换行也不会破坏它。

## 输出语言

支持简体中文、繁体中文和英文，按 `LC_ALL`、`LANGUAGE`、`LC_MESSAGES`、`LANG` 的顺序从环境推断，
其他语言一律回退英文。`--lang` 可无视环境强制指定。

## 已知限制

* 只支持**块设备上的 ext4**，且只搜索**根文件系统**；tmpfs、btrfs、XFS、NFS、FUSE 均不支持。
* 没有索引缓存，每次调用都重新扫描。
* 模式只作用于文件名，不支持 glob。
* 挂载点对扫描是透明的：被挂载点遮蔽的底层内容也会被搜到；`--path` 同样按盘上目录结构解释，不解析符号链接。
